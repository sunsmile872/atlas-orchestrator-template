## How to Resume Any Project in a New Chat
1. Open this repository folder in your workspace.
2. Start a **New Chat** and type: `@atlas resume [Project_Name]`
3. Atlas reads `projects/[Project_Name]/PROJECT.md`, `SOT.md`, and `ROADMAP.md` automatically.
